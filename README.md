# Unemployed

A Godot 4 roguelike dungeon crawler game.

## Project Structure

- **assets/** - Game assets (sprites, audio, fonts, animations)
- **scenes/** - Godot scene hierarchy
- **scripts/** - GDScript modules
- **resources/** - Resource files (TRES, TSCNs)
- **tests/** - Test suite
- **docs/** - Documentation

## Getting Started

1. Open the project in Godot 4.x
2. Load `project.godot` configuration
3. Run the game via the Godot editor
