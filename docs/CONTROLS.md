# Controls

## Movement

- **WASD** or **Arrow Keys** - Move character
- **Space** - Interact / Open doors

## Combat

- **Left Click** - Basic attack / Skill use
- **Right Click** - Block / Dodge
- **Q/E** - Cycle skills

## UI

- **Esc** - Open pause menu
- **I** - Open inventory
- **M** - Open map
