# Game Design Document

## Core Concept

Unemployed is a roguelike dungeon crawler where you play as a recently unemployed character navigating through procedurally generated dungeons, fighting enemies, and collecting skills to survive.

## Key Features

- Procedurally generated dungeon rooms
- Skill-based combat system
- Permanent progression between runs
- Boss encounters at the end of each level

## Gameplay Loop

1. Enter dungeon room
2. Fight enemies or choose skill path
3. Defeat boss to progress
4. Gain meta-progression upgrades
5. Attempt to reach deeper levels
